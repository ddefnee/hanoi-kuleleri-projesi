# Hanoi Kuleleri

C# Windows Forms ile geliştirilmiş, **sürükle-bırak** ile oynanan görsel bir Hanoi
Kuleleri (Tower of Hanoi) oyunu.

## 🎮 Özellikler

- 3 ile 8 arası seçilebilir disk sayısı
- Diskleri fare ile sürükleyip bırakarak kule değiştirme
- Hamle sayacı
- Her disk için ayrı pastel renk
- Disk hareketinde ses efekti

## 🛠️ Teknoloji

- C# / .NET (Windows Forms)
